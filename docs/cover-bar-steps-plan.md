## 정한 것

- **커버 탭 배치**(사용자 요청): 자르기 자리에 이동, 브러시 자리에 흐림. 탭은 이동·선택·흐림·리터칭·유동화·더보기다. 자르기·브러시는 더보기 줄에서 이동·흐림이 있던 자리로 옮긴다(더보기: 자르기·지우개·텍스트·명암·브러시·모자이크, 서로 자리를 바꾼 것으로 봄, Claude 판단). 펼친 화면 도구 막대는 그대로.
- **막대의 하위 도구 칩 빼기**(사용자 요청, 동의): 커버 막대·가로 기둥 맨 앞의 하위 도구 칩(선택·리터칭·명암·흐림)을 뺀다. 하위 도구는 하위 도구 메뉴로만 고른다(탭을 꾹 누르거나 고른 탭을 다시 누름, 펼친 화면과 같음). 탭 아이콘이 고른 하위 도구 모양이고 작은 삼각형이 있어 메뉴가 있는 줄 안다.
  - 더보기 줄의 도구도 꾹 누르면(0.3초) 하위 도구 메뉴가 뜬다(지금은 열지 않음). 하위 도구를 고르면 그 도구를 고르고 더보기 줄을 닫는다. 더보기 도구를 고른 동안 더보기 칸을 꾹 누르면 그 도구의 하위 도구 메뉴다(그 도구에 하위 도구가 있으면 더보기 칸에도 작은 삼각형). 이유(Claude 판단): 칩을 빼면 명암처럼 더보기 줄에 있는 도구는 하위 도구를 고를 길이 없다.
- **늘 고른 도구·✕ 빼기·뒤로 가기는 홈**(사용자 요청, 커버만):
  - 커버 편집 화면은 늘 도구 하나를 골라 둔다. 처음 열 때, 새 창(자르기·유동화)을 닫고 돌아올 때, 펼친 화면에서 도구 없이 접을 때는 첫 탭(이동)이다(사용자: "기본 값이 첫번째 도구로 옵니다". 새 창 전에 고른 도구로 돌아가지 않는다). 고른 탭을 다시 눌러도 내려놓지 않는다(하위 도구가 있으면 지금처럼 메뉴).
  - 막대 오른쪽 끝·가로 기둥 맨 아래의 ✕를 뺀다. 조정을 켰을 때 같은 자리의 ✕(조정 끄기)도 뺀다(Claude 판단: 같은 자리의 같은 버튼이라. 조정은 상단 바 조정 버튼·도구 탭·뒤로 가기로 끈다). 펼친 칩의 ✓는 그대로.
  - 뒤로 가기: 떠 있는 것(창·하위 도구 메뉴·더보기 줄·고른 물체·펼친 칩·조정·레이어)을 지금처럼 하나씩 닫고, 그다음은 바로 홈이다(도구를 닫는 단계만 뺌). 새 창(자르기·유동화)의 뒤로 가기는 지금처럼 X와 같다(닫고 이동).
  - 안내 글 막대('아래에서 도구를 골라요'·'오른쪽에서 도구를 골라요')와, 그때 레이어 시트가 막대 자리까지 덮던 것(2026-10-22)을 없앤다. '작업 전에 물어볼 것'의 처음 화면 막대 질문은 이것으로 정해진다.
  - 키보드 Esc도 커버에서는 도구를 내려놓지 않는다(떠 있는 것·자르기만 닫음).
  - 펼친 화면은 그대로다(도구를 내려놓을 수 있고 뒤로 가기는 도구부터 닫음). 펼친 화면에서 도구 없이 접으면 이동이 골라져, 다시 펴면 이동 띠가 보인다.
- **펼친 수치 줄 정렬**(사용자 요청, 커버 수치 조절 공통): 칩을 눌러 펼친 줄 [이름 | 슬라이더 | 값 | ✓]에서 이름은 막대 왼쪽 끝과 슬라이더 시작 사이 빈 곳의 가운데, 값은 슬라이더 끝과 ✓ 사이의 가운데에 둔다(지금은 이름이 왼쪽 끝에 붙고 값이 ✓에 붙음).
  - 도구 슬라이더(브러시·지우개·리터칭·명암·흐림·모자이크, 선택의 페더·허용치, 글자 도구 막대의 크기), 조정 슬라이더, 유동화 막대(크기·압력·얼굴) 모두.
  - 가로로 돌린 커버의 펼친 기둥도 같은 차례를 돌려 위에서 아래로 [이름 | 슬라이더 | 값 | ✓]로 바꾼다(Claude 판단: 지금은 이름·값이 함께 위에 있다). 이름은 기둥 위 끝과 슬라이더 사이 가운데, 값은 슬라이더 끝과 ✓ 사이 가운데.
  - 창 안의 슬라이더 줄(글자 창의 크기 등)은 그대로다(Claude 판단: 창의 다른 칸과 왼쪽을 맞춘 줄이다). 펼친 화면 조정 패널도 그대로.
- **A 칩 끌기**(커버): 값 칩을 누른 채 끌면 바로 값이 바뀐다(200dp가 처음~끝, 펼친 화면 띠의 수치 끌기와 같은 눈금). 톡은 지금처럼 슬라이더 줄.
  - 세로 커버 막대는 위로 끌면 커진다(펼친 화면 띠와 같음).
  - 가로 커버 기둥은 캔버스 쪽(왼쪽)으로 끌면 커진다. 세로 커버의 '위로 끌기'를 그대로 돌린 것이다(Claude 판단: 기둥은 위아래로 밀어 보는 줄이라, 위아래 끌기를 쓰면 칸이 많은 조정 기둥을 밀어 볼 수 없다).
  - 끄는 동안 값은 캔버스 위쪽 알림 자리에 '크기: 84 px'로 손을 뗄 때까지 보인다(손가락이 칩을 가려서, 스냅시드처럼 값은 위에. 화면 읽기 기능이 끄는 값을 하나하나 읽지 않게). 크기·경도는 지금처럼 크기 원도.
- **꾹 눌러 0**(공통 수치 칸 기능, -100~100 수치만, 사용자 결정): 커버 조정 칩 7개(곡선 빼고)와 유동화 얼굴 슬라이더(펼친 화면 띠 칸·커버 칩).
  - 0.3초(메뉴 묶음, 레이어 줄과 같음) 움직이지 않고 누르고 있으면 짧은 진동, 그대로 떼면 0과 알림 '밝기 값을 0으로 되돌렸어요'. 진동 뒤라도 끌면 0이 아니라 값을 바꾼다(Claude 판단: 끌기 전에 잠깐 멈춘 것만으로 0이 되는 실수를 막으려고). 이미 0이면 진동만.
  - 크기·경도·불투명도 같은 0~100 수치는 꾹 눌러도 아무 일 없다.
- **C 누른 채 끌어 고르기**: 고르기 칩(명암 범위·선택 합치는 방법·유동화 얼굴 부위, 하위 도구 칩은 위에서 뺌)을 0.3초 누르면 칩 위(가로 커버는 칩 왼쪽)에 고를 것 목록이 뜬다. 누른 채 옮기면 손가락 밑 항목이 하이라이트(짧은 진동), 떼면 고른다. 항목 밖에서 떼면 목록은 열린 채 남아 눌러 고른다(밖을 누르거나 뒤로 가기로 닫힘). 탭 줄의 하위 도구 메뉴(7차)와 같다. 톡은 지금처럼. 선택 '동작' 칩은 넣지 않는다(바로 실행되는 편집이라, Claude 판단).
- 칩 끌기·꾹 눌러 0은 바로 적용된다. 도구 값은 지금 슬라이더처럼 바로 바뀌고, 조정 칩은 끄는 동안 미리 보다가 떼면 실행 취소 한 단계, 꾹 눌러 0도 한 단계다(지금 슬라이더·이름 두 번 톡과 같음). 펼친 줄의 ✓는 지금 그대로다(취소 요청은 뺌).
- 펼친 화면 조정 패널은 그대로(놓을 때마다 적용, 이름·원 두 번 톡 초기화). 펼친 화면 띠의 세로 슬라이더 창도 그대로. 띠에서는 얼굴 슬라이더 칸만 꾹 눌러 0이 더해진다(공통 수치 칸 기능).

   - 지우는 것: `CoverToolBar`·`CoverToolColumn`의 ✕와 `onClose`·`closeDescription`, `EditScreen`의 안내 글과 `sheetCoversBar`, `CoverLayerSheet`·`CoverLayerPanel`의 `extra`, 안 쓰게 된 문구 두 언어(`bar_hint_choose_tool`·`bar_hint_choose_tool_side`·`bar_close_tool`). 칩이 없는 막대의 흐린 글자(`empty`·`BAR_HINT`)는 유동화 얼굴 안내가 그대로 쓴다.
   - 테스트: `EditScreenBackTest`(커버 처음 이동, 도구를 고른 채 뒤로 → 홈, 칩을 접은 뒤 홈, 자르기 뒤로 → 취소하고 이동, 유동화를 열면 이동, 이동 탭을 다시 눌러도 그대로, 펼친 화면은 그대로), ✕·안내 글을 보던 `AdjustPanelTest`·`CoverOptionsTest`·`EditToolsTest`·`LayerPanelTest`·`CoverLandscapeTest`·`BrushToolsTest`를 고친다.
2. **펼친 수치 줄 정렬**: `OptionSlider`(BrushOptions.kt)와 `AdjustSliderRow`(AdjustPanel.kt)에 글자를 가운데 맞추는 값(예: `centered`)을 더해, 이름·값 칸(이름 88dp, 값 64dp·48dp) 안에서 가운데 맞춘다. 커버 막대(`BarExpanded`, 조정 `adjustBar`)만 켜고, 글자 창·펼친 화면 조정 패널은 그대로. 가로 기둥(`BarExpandedColumn`의 값 칸, `AdjustSliderColumn`)은 [이름 칸 | 세로 슬라이더 | 값 칸]으로 바꾸고 두 칸을 같은 높이로 가운데 맞춘다. 화면 테스트는 글자 배치 결과(`GetTextLayoutResult`)로 글자 가운데가 그 빈 곳 가운데에 있는지 잰다(세로·가로).
3. **공통 손가락 처리** `Modifier.valueGestures(slider, axis, enabled, …)`(ui/edit/OptionStrip.kt): 터치를 하나로 처리한다(Initial 단계, `longPressFirst`와 같은 방식). 겹쳐 쌓으면 0.3초 멈춘 뒤의 끌기를 꾹 누르기가 삼킨다.
   - 톡이면 아무것도 하지 않아 안쪽 누르기(지금 동작)가 받는다.
   - 정한 축(`axis`)으로 터치 허용 거리를 넘게 움직이면 끌기, 다른 축이면 놓아 둬 밀어 보기가 받는다.
   - 0.3초(`LongPressTimes.MENU_MILLIS`) 움직이지 않으면 진동, 그대로 떼면 `onReset`(있을 때만).
   - 펼친 화면 띠 칸(`ValueCellView`)의 지금 수치 끌기를 이것으로 바꾼다(세로축, 결과는 같음).
   - 알림: 새 `LocalValueFeedback`(끄는 값 보이기·0 알림)을 편집 화면과 유동화 창이 넣는다(유동화 창이 편집 화면 알림 위를 덮어서 창 안에 따로). `GestureToastState`에 손을 뗄 때까지 보이고 화면 읽기가 읽지 않는 '끄는 값' 모드.
   - 화면 읽기: 0이 되는 칸·칩에 '밝기 초기화' 동작(`CellBox`의 의미에 넣는다, 지금은 `touch` 수식어의 의미가 지워짐). 고르기 칩에 목록을 여는 길게 누르기 동작(탭 줄처럼).
4. **커버 칩**(CoverToolBar.kt `BarChip`, CoverToolColumn.kt `BarCell`): 값 칩·조정 칩에 `valueGestures`(막대는 세로축, 기둥은 가로축), 고르기 칩에 목록 열기(7). 칩 줄은 `key(item.key)`로 감싼다(도구를 바꿔도 끄던 상태가 넘어가지 않게).
5. **조정 칩**(AdjustPanel.kt `AdjustChip`·`AdjustCell`): 끌기는 지금 슬라이더와 같이 미리 보기(`preview`) 후 떼면 한 단계(`commit`), 꾹 눌러 0은 한 단계(`record { item.resetIn(it) }`, 이름 두 번 톡과 같음). 곡선 칩·모두 초기화는 그대로.
6. **유동화**(LiquifyMode.kt): 막대를 한 번만 만들고(지금 두 번 만듦), 목록 호스트와 `LocalValueFeedback`을 창 안에 둔다. 얼굴 칩·칸의 0은 지금 있는 `onReset`(`resetFaceValue`).
7. **C 목록**: `SubToolMenu.kt`의 자리 계산·밖 누르기 바탕을 함께 쓰는 함수로 꺼내고(하위 도구 메뉴 동작은 그대로), 새 `ChipMenu.kt`를 만든다.
   - `ChipMenuState`는 칩 이름·자리·쪽만 들고, 고를 것은 그때의 막대에서 찾는다(고를 것의 할 일이 지난 값을 잡지 않게). 막대 내용·배치가 바뀌면 닫는다.
   - `ChipMenuHost`의 줄 이름표는 `chipMenu_<고를 것 이름표>`(펼친 줄의 이름표와 겹치지 않게). 호스트는 편집 화면과 유동화 창에 둔다.
8. **문구** 두 언어: '%1$s 값을 0으로 되돌렸어요' / '%1$s reset to 0'. 있는 문구도 쓴다(`strip_choice_description`, `adjust_reset_item`).
