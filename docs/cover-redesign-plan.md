## 1단계에서 하는 것

### 1. 아래 높이 고정(도크)

- 전: 아래에는 탭 줄(80dp)만 있었다. 도구·조정·레이어를 고르면 옵션 칸이 사진 아래쪽 위에 겹쳐 떴다(브러시는 약 208dp, 선택·레이어는 약 230~360dp를 가림).
- 뒤: 아래는 늘 [한 줄 막대 56dp] + [도구 탭 줄 56dp]이고, 캔버스는 그 위만 쓴다.
  - 도구를 바꾸거나 닫아도 높이가 같아서 사진 크기·자리가 그대로다.
  - 막대가 사진을 가리지 않는다.
- 대가: 도구를 고르지 않았을 때 보이는 캔버스가 32dp 짧아진다(80dp → 112dp).
- 도구를 고르지 않았을 때 막대에는 흐린 글자 '아래에서 도구를 골라요'를 둔다(Claude 판단).

### 2. 도구 탭 줄

- 탭은 [자르기][선택][브러시][리터칭][유동화][더보기]다(사용자 지정). 여섯 칸이 화면 폭을 똑같이 나누고, 옆으로 밀어 보지 않는다.
- 더보기를 누르면 막대 위에 나머지 도구 여섯(이동·지우개·텍스트·명암·흐림·모자이크)이 한 줄로 뜬다.
  - 하나를 고르면 닫힌다. 더보기 칸은 그 도구의 아이콘·이름으로 바뀌어 켜진다.
  - 더보기 칸을 다시 누르거나, 뒤로 가기를 누르거나, 캔버스를 만지면 닫힌다(Claude 판단: 고르는 메뉴라 잠깐만 뜬다).
- 조정·레이어는 탭에서 빠지고 상단 바 버튼이 된다(4번).
- 그대로인 것:
  - 자르기·유동화는 누르면 새 창이 열린다.
  - 하위 도구가 있는 탭은 꾹 누르거나 다시 누르면 하위 도구 메뉴가 열린다.

### 3. 한 줄 막대(모든 도구가 같은 틀)

- 틀: [하위 도구 ▾] [색] [값 칩…] [동작 ▾] … [✕]. 없는 칸은 뺀다.
  - 칸이 넘치면 칩만 옆으로 밀어 본다. ✕는 늘 오른쪽 끝에 있다.
- 값 칩(크기 60 px, 경도 50% 등)을 누르면 같은 줄이 [이름 슬라이더 값][✓]로 바뀐다. ✓를 누르면 칩 줄로 돌아온다.
  - 크기·경도는 끄는 동안 캔버스 가운데에 크기 원이 보인다(전과 같다).
- 고르기 칩(하위 도구·범위·합치는 방법 등)을 누르면 같은 줄이 고를 것들로 바뀌고, 하나를 고르면 돌아온다.
- 색 칩(전경색 위에 배경색이 겹친 동그라미)을 누르면 [전경색][배경색][바꾸기][스포이드][✓] 줄로 바뀐다. 색을 누르면 전처럼 팔레트 시트가 열린다.
- 동작 칩(선택 도구)을 누르면 동작 버튼 줄(옆으로 밀어 봄)로 바뀐다. 동작을 눌러도 줄은 남고, ✓로 돌아온다(Claude 판단: 모두 선택 → 지우기처럼 이어서 누를 때가 많다).
- ✕를 누르면 도구가 닫힌다.
- 뒤로 가기: 슬라이더·고르기·색·동작 줄이면 칩 줄로 돌아오고, 칩 줄이면 도구를 닫는다(도구가 없으면 전처럼 홈).
- 도구별 칸(순서는 메인 띠와 같은 규칙: 수치가 아닌 칸 → 크기 → 경도 → 불투명도 → 강도):
  - 브러시: 색 · 크기 · 경도 · 불투명도
  - 지우개: 크기 · 경도 · 불투명도
  - 텍스트: 색 · 크기
  - 선택: 하위 도구(사각형 등) · 합치는 방법(새로 등) · 페더(자동 선택은 허용치·이어진 곳만) · 동작(모두·해제·반전·지우기·복사·잘라내기·AI 채우기)
  - 리터칭: 하위 도구 · 크기 · 경도 · 불투명도(복제만). AI 제거는 [지우기]가 있고, 물체를 고르면 켜진다.
  - 명암: 하위 도구 · 범위 · 크기 · 경도 · 노출
  - 흐림: 하위 도구 · 크기 · 경도 · 강도
  - 모자이크: 크기 · 경도 · 셀 크기
  - 이동: 옵션이 없다. 막대에는 '이동'과 ✕만 있다(Claude 판단: 막대가 비어 보이지 않게).
- 값·이름표·하는 일은 메인 띠와 같은 것을 쓴다. 그래서 커버와 메인이 늘 같다.

### 4. 상단 바 [조정][레이어] 버튼(메인 화면과 같은 자리)

- 켬·끔은 메인 화면 패널과 같은 상태다. 접고 펴도 이어진다.
  - 그래서 메인에서 패널을 켠 채 접으면 커버에서도 그 조정·레이어가 보인다. 전에는 도구를 고른 채 접으면 도구만 보였다.
  - 한 번에 하나다(메인과 같다).
- 조정(Q1 A, 사용자 결정): 막대가 조정 칩(노출·밝기·대비·하이라이트·그림자·색온도·채도·곡선, 모두 초기화)으로 바뀐다.
  - 칩을 누르면 슬라이더 한 줄이 된다(원 두 번 톡·이름 두 번 누르기로 그 항목 초기화는 전과 같다).
  - 곡선은 누르면 막대 위에 곡선 편집기가 뜬다(곡선은 넓은 자리가 필요해서).
  - 조정을 끄면 막대가 고른 도구로 돌아온다. 도구 탭을 누르면 조정이 꺼지고 그 도구가 보인다(같은 막대를 쓰므로).
- 레이어(Q2 A, 사용자 결정): 막대 위로 시트가 올라온다. 내용은 전의 레이어 패널과 같다(목록·더하기·지우기·화면 반전·불투명도·혼합 모드).
  - 레이어 버튼을 다시 누르거나, 손잡이를 끌어 내리거나, 뒤로 가기를 누를 때만 닫힌다.
  - 캔버스를 쓰거나 도구를 바꿔도 열려 있다. 시트를 열어 둔 채 보이는 캔버스에 칠할 수 있다.
  - 메인 패널과 다른 점: 뒤로 가기로도 닫힌다. 안드로이드에서 아래 시트는 뒤로 가기로 닫히는 것이 보통이라서다.
  - 막대 위에 뜨므로 막대(고른 도구의 칩)는 그대로 쓸 수 있다(Claude 판단).

### 5. 새 창 맞추기

- 유동화(커버): 위의 크기·압력 칸을 같은 한 줄 막대(칩을 누르면 슬라이더)로 바꾼다. 맨 아래 [X | 도구 | ✓]는 그대로다.
- 자르기·회전 창: 배치는 그대로다(이미 맨 아래 [X | 탭 | ✓]와 한 줄 옵션). 옵션 줄의 높이·색만 막대와 맞춘다.

1. 탭 줄·더보기·상단 바 버튼
   - 탭 줄을 56dp 높이의 [자르기][선택][브러시][리터칭][유동화][더보기]로 바꾸고, 더보기 줄을 만든다.
   - 커버 상단 바에 [조정][레이어] 버튼을 둔다. 이 작업에서는 누르면 전의 조정·레이어 내용을 전의 옵션 칸에 보인다(모양은 작업 4에서 바꾼다).
   - 조정·레이어는 도구가 아니라 패널이 된다. 접고 펼 때 탭과 패널을 바꿔 주던 코드가 필요 없어진다.

## 코드 메모(이어서 작업할 때)

- 전 커버 배치: `EditScreen`의 Compact 분기. `EditCanvas(floating = ToolOptionsSheet)`가 캔버스 아래쪽에 옵션 칸을 겹치고, `ToolTabBar`(M3 NavigationBar 80dp)가 13개 탭(`EditTool.tabTools`)을 옆으로 밀어 봤다.
- 옵션 칸 높이를 쓰는 곳: `coverSheetPx`·`coverSheetInset`(알림 막대 `overlayBottom`, `SizePreviewOverlay`의 `bottomInset`, 리터칭 `sourceSpot`의 `hiddenBottom`). 막대 위에 뜨는 것(더보기·레이어 시트·곡선)이 캔버스를 덮으면 같은 길로 알린다.
- 막대 칸은 메인 띠와 같은 `…Controls`와 슬라이더 칸 만들기(`sizeCell`·`hardnessCell` 등, `StripSlider`: 0..1 비율·`onFraction`·`onFinished`·`preview`)를 쓴다. 띠의 칸 그림은 세로 줄용이라 가로 막대 그림은 새로 만든다.
  - 띠에 없는 것: 하위 도구, 선택 동작(메인은 `SelectionActionBar`), 크기 변경.
  - 펼친 슬라이더 줄은 커버 옵션의 `OptionSlider`(같은 이름표)를 쓰고 `EndPreviewOnDispose(slider.preview)`를 부른다.
- 조정·레이어 내용: `AdjustCompact`(칩 + 슬라이더 하나·곡선), `AdjustList`, `LayerCompact`, `LayerColumn`. 메인 패널은 `FloatingPanelHost`·`PanelToggles`, 상태는 `FloatingState.panel`이다.
- 접고 펼 때 탭과 패널을 바꾸던 코드: `EditScreen`의 `LaunchedEffect(widthClass)`.
- 새 창: 자르기 `coverCropWindow`(`CoverWindowTopBar`·`CoverCropOptions`·`CoverWorkBar`·`CoverCropTabs`), 유동화 `LiquifyMode`의 Compact 분기(`LiquifyOptions`·`LiquifyToolTabs`).
