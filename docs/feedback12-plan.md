# 사용자 피드백 12차: 오른쪽 수치 조절 바, 레이어 돌리기, 커버 가로, 사진 넣기·끌어 놓기, 키보드·마우스

## Context(배경)

펼친 화면 점검 보고에 대한 사용자 답과 새 요청(2026-10-22). 원문은 시작할 때 progress.md '진행 중'·history.md에 그대로 옮긴다.

- 답: 세로 화면 패널은 현행 유지, 프로젝트 이름은 보류, 커버를 가로로 돌리면 "커버화면 배치가 돌아간형태", "사진 끌어다 놓아 열기, 키보드 마우스 단축키 먼저 하고 나머지는 보류".
- 우선 작업(먼저 하고 APK를 올린 뒤 나머지):

  1-1. "레이어 패널이 펼쳐지면 수치 조절 바가 부드러운 애니메이션과 함께 하단 중앙으로 이동합니다. (선택 도구의 액션 보여지는 위치로)"
  2. "자르기에서 회전 작업 시 선택된 레이어만 회전이 되어야하는데, 전체 레이어가 회전되는 버그가 있습니다."
- 질문으로 정한 것(사용자 결정)
  - 회전: 설계대로 이미지 전체를 돌린다고 알리고 포토샵(이미지 회전 ↔ 편집 > 변형)·프로크리에이트(캔버스 ↔ 변형 도구)를 조사해 알림 → "이동 도구에 레이어 돌리기 (추천)". 자르기·회전 창은 그대로 이미지 전체.
  - 커버 가로: "막대를 오른쪽 세로로". 아래 가운데로 옮긴 바: "가로 슬라이더 한 줄 (추천)".
  - 사진 넣기: 편집 화면에 끌어다 놓으면 새 레이어(홈에 놓으면 새 프로젝트). 더해서 "레이어 패널의 + 오른쪽에 이미지 아이콘이나 카메라 아이콘으로 사진 추가 가능하도록 하세요."

## 순서

단계마다: `git status` 확인 → 빌드·단위 테스트(`./gradlew assembleDebug test`) → 바뀐 곳 에뮬레이터 테스트(자동 회전 끔, 에뮬레이터만) → progress.md·history.md(필요하면 CLAUDE.md) → 그 단계 파일만 경로로 커밋. 4단계 뒤와 맨 끝에 전체 에뮬레이터 테스트.

progress.md '진행 중'에 요청·답·계획, 결정 기록에 사용자 결정(세로 패널 그대로, 프로젝트 이름 보류, 커버 가로 = 오른쪽 세로 막대, 태블릿 순서). '작업 전에 물어볼 것'에서 끝난 질문을 지운다.

### 1. 오른쪽 수치 조절 바 (펼친 화면·유동화)
- 새 부품 `ui/components/ToolSliderTrack.kt`: 둥근 어두운 트랙 + 밝은 알약 손잡이(채움 없음, 프로크리에이트 느낌). 높이가 폭보다 크면 세로(위 = 큼), 아니면 가로. 누른 자리로 튀지 않고 끈 만큼 움직임(톡은 바꾸지 않음), 놓으면 끝(`finally`로 사라져도 끝냄). 화면 읽기: 이름·값·진행 범위·값 넣기. `StratumVerticalSlider`는 이것으로 바뀌어 지운다.
- 새 토큰 `sliderBarTrack`·`sliderBarThumb`(다크·라이트, `ui/theme/Color.kt`, `ThemeColorsTest`).
- 자리 계산(순수 함수, `ui/layout/Placement.kt`, JVM 테스트): 캔버스 오른쪽 가장자리·세로 가운데, 슬라이더 1~3개, 캔버스가 낮으면 트랙을 줄임(누르는 폭 48dp, 보이는 트랙 약 28~32dp, 길이 약 80~160dp, 폴드8에서 써 보고 고칠 수 있게 한곳에).
- 새 `ui/edit/ToolSliderBar.kt`: 패널 색 카드 안에 슬라이더. 이름표는 늘 두지 않고, 끄는 동안 바 옆에 '크기 60 px' 말풍선. 크기·경도는 지금처럼 캔버스 가운데 크기 원. 슬라이더 이름표는 지금 것(`BRUSH_SIZE` 등) 그대로.
- 띠 나누기: 도구 띠 목록(`ToolStrips.kt`)은 그대로 두고 쓰는 곳에서 수치 칸(`SliderCell`)과 나머지로 나눈다(`splitSliders`, JVM 테스트). 커버 막대는 그대로다. 수치 칸 순서가 이미 크기 → 경도 → 불투명도 → 그 밖이라 그대로 바에 넣고, 셋을 넘는 칸이 생기면 띠에 남긴다(지금은 없음).
  - 띠는 남은 칸이 있을 때만 뜬다(지우개·흐림·모자이크·스팟 복구·복구·복제는 띠 없이 바만).
  - 자동 선택의 '이어진 곳만'은 슬라이더 창 안에 있었으므로 띠의 켜고 끄는 칸으로 옮긴다(Material Icons `link`).
- 쓰지 않게 되는 것을 지운다: 띠의 세로 슬라이더 창(`VerticalSliderFlyout`·화살표), 수치 끌기(`ScrubFullRange`), 커버에 안 쓰는 `SliderCell.extra`. (사용자 피드백 5차의 세로 슬라이더 창·9차의 수치 끌기를 이번 '오른쪽 바에서 일괄 조절'이 대신한다.)
- `EditScreen.kt`(띠·바 배치), `LiquifyMode.kt`(띠는 도구 칸 넷, 바는 크기·압력).
- 테스트: 새 `ToolSliderBarTest`(자리·순서·톡은 그대로·끌기·말풍선·크기 원·띠 없는 도구·유동화), `StratumComponentsTest`에 트랙. 띠 수치 칸을 누르던 테스트(`OptionStripTest`·`SizePreviewTest`·`LiquifyModeTest`·`SelectionToolTest`·`BrushToolsTest`·`EffectToolsTest`·`FloatingPanelTest` 등)를 바로 바꾼다.

### 2. 패널을 열면 아래 가운데 가로 한 줄로
- 레이어·조정 패널이 떠 있으면(조정도 같은 오른쪽 위 자리라 함께, Claude 판단) 바가 화면 가로 가운데·캔버스 아래 8dp 위(선택 작업 표시줄 자리)로 가며 가로 슬라이더 한 줄이 된다. 선택 도구면 작업 표시줄 위에 쌓는다.
- 애니메이션: 0→1 진행값(약 0.25초)으로 바 상자와 슬라이더 칸의 자리를 옆 ↔ 아래 사이에서 이어 그린다(순수 자리 함수, JVM 테스트). 슬라이더는 모양이 가로가 되는 순간 가로로 그린다. 진행값은 배치 단계에서만 읽어 매 장면 다시 짜지 않는다.
- 패널 아래 여백과 알림 막대는 바 높이만큼 위로(선택 작업 표시줄과 같은 방식).
- 테스트: 열면 아래 가운데·가로, 작업 표시줄 위에 쌓임, 패널·알림 막대가 위, 닫으면 오른쪽으로 돌아옴(시계를 멈춰 중간 장면도 봄).

### 3. 레이어 돌리기·뒤집기 엔진
- 새 명령 `OrientLayer(layerId, orientation)`(`TransformCommands.kt`, `TranslateLayer`와 같은 틀): 고른 레이어만, 내용(투명하지 않은 곳)의 테두리 가운데를 축으로 90°·뒤집기, 캔버스 크기 그대로, 밖으로 나간 곳은 잘림, 픽셀 값 그대로(다시 그리지 않음), 게인맵도 같은 비율로, 실행 취소 한 단계. 왼쪽으로 돌린 뒤 오른쪽으로 돌리면 정확히 제자리(자리 계산의 반올림을 맞춤).
- 내용 테두리 `ContentBounds`(순수 Kotlin + 타일 알파 읽기): 빈 타일은 건너뛰고, 가장 바깥 타일 줄에서만 안쪽으로 읽다가 처음 보이는 픽셀에서 멈춘다(사진처럼 꽉 찬 레이어는 바로 끝남). 큰 사진을 다 도는 것이 아니라 바깥 타일만 읽어 CLAUDE.md 2장의 예외로 결정 기록에 남긴다(오래 걸리면 GPU로 바꿈).
- `TransformPlan`에 '같은 캔버스 안에서 한 점을 축으로 돌리기·뒤집기'를 더한다(8단계의 '가운데 놓기'도 같은 틀).
- 테스트: JVM(자리 계산·테두리·되돌리면 제자리·뒤집기), 에뮬레이터 `OrientLayerTest`(픽셀 정확·게인맵·다른 레이어·선택 그대로).

### 4. 레이어 돌리기 화면 → APK
- 이동 도구에 옵션이 생긴다: 펼친 화면 띠에 [왼쪽 90°][오른쪽 90°][좌우 뒤집기][상하 뒤집기](자르기 창과 같은 아이콘), 커버 막대에 같은 버튼 넷. 숨긴 레이어는 알림, 글자 레이어는 '글자를 픽셀로 바꿀까요?'를 먼저 묻는다(다른 한 번에 하는 일과 같음, Claude 판단).
- 문구 두 언어, 결정 기록 '이동 도구'('고를 옵션이 없다'를 바꿈)·'레이어 돌리기·뒤집기'.
- 1~4단계 검토(CLAUDE.md 3장), 전체 에뮬레이터 테스트, APK를 구글 드라이브에 올리고 중간 보고(멈추지 않고 5단계로).

### 5. 커버 가로: 배치 규칙과 뼈대
- 화면 짧은 쪽이 600dp보다 작으면 커버 배치(그래서 커버·폰을 가로로 돌려도 커버 배치), 아니면 지금처럼 폭으로 메인 세로·가로. 커버 배치이면서 가로가 더 길면 '돌아간 형태'. 창(시트 ↔ 가운데 창)도 같은 규칙. 홈 격자 칸 수·설정 2단은 지금처럼 폭으로(Claude 판단: 넓은 화면을 쓰게).
- 돌아간 형태: 위 상단 바는 그대로, 그 아래 [캔버스 | 세로 한 줄 막대 | 세로 도구 탭]. 커버 편집 화면 본문을 `CoverLayout.kt`로 옮기고 `vertical`로 나눈다. 하위 도구 메뉴는 탭 왼쪽에 뜬다.
- 테스트: JVM 배치 규칙(751×475·797×411·891×411은 커버 가로, 704×933 메인 세로, 933×704 메인 가로), 새 `CoverLandscapeTest`(797×411·751×475), 낮고 넓은 창을 메인으로 보던 테스트(900×320)를 고친다.

### 6. 커버 가로: 세로 막대·더보기·오른쪽 패널
- 세로 한 줄 막대: 칩을 위아래로 쌓고 펼친 띠 칸처럼 두 줄(이름·값), 맨 아래 ✕·✓. 값 칩을 누르면 같은 기둥이 세로 슬라이더(1단계의 트랙), 고르기는 세로 목록, 색은 세로 색 버튼, 조정 칩도 같다.
- 더보기 줄은 막대 자리에 세로로. 레이어 시트·곡선 편집기는 캔버스 오른쪽에 붙는 패널(도구가 없으면 막대 자리까지 덮음, 지금 규칙과 같음).
- 알림 막대·크기 원·가져올 곳 자리는 오른쪽 패널을 피한다.

### 7. 커버 가로: 새 창
- 자르기·회전 창과 유동화 창의 맨 아래 [X | 탭 | ✓]는 오른쪽 기둥(✓ 위, X 아래, 탭은 그 사이)이 된다. 옵션 줄도 기둥 폭으로(탭을 바꿔도 사진 크기 그대로).
- CLAUDE.md 6장 표·커버 규칙, 결정 기록('커버 가로 대응 안 함' 답을 바꿈).

### 8. 사진 넣기(레이어 패널 버튼)
- 레이어 패널·시트의 + 오른쪽에 사진 추가 버튼(Material Icons add_photo_alternate). 누르면 사진 선택기, 고른 사진이 고른 레이어 위 새 레이어(캔버스보다 크면 맞게 줄여 가운데, 작으면 그대로 가운데), 그 레이어를 고름, 실행 취소 한 단계, 문서 색 공간(sRGB·P3)으로, 게인맵 없음.
- 엔진 `InsertImageLayer`: 문서보다 크면 줄여 읽기 → 타일 → 크면 GPU로 줄임 → 가운데 놓기. 사진 열기·크기 변경의 타일 나누기를 함께 쓰는 엔진 안 도우미로 묶는다. 메모리는 `makeRoom`으로.
- 레이어 이름: 파일 이름(사진 선택기가 주는 숫자 이름이면 '사진 N').
- 메인 떠 있는 패널(280dp)은 버튼이 다섯이 되어 '레이어' 제목이 들어가지 않는다 → 자리가 모자라면 제목 글자를 숨긴다(화면 읽기 창 이름은 그대로, Claude 판단: 사용자가 정한 폭을 지키고 버튼 자리를 바꾸지 않게). 커버 시트는 넓어 그대로.
- 테스트: JVM(맞춤 크기·이름), 에뮬레이터(작은 PNG 정확히 가운데, 큰 사진 줄임, P3, 실행 취소, 버튼·제목줄).

### 9. 끌어 놓기
- 다른 앱(창 나누기한 갤러리 등)에서 사진을 끌어 오면: 편집 화면은 8단계와 같이 새 레이어, 홈은 새 프로젝트(사진 열기와 같은 길, 파일 이름이 프로젝트 이름). 끄는 동안 놓을 곳을 표시. 첫 사진 하나만.
- 받은 읽기 권한은 화면이 다시 만들어지면(접기·펼치기) 사라지므로, 놓자마자 앱 임시 폴더에 복사해 읽고 지운다. 새 권한·라이브러리 없음.
- CLAUDE.md 5장 '사진 선택기만'에 '끌어 놓기'를 더한다(사용자 요청).
- 테스트: 복사·정리·첫 사진 고르기(에뮬레이터), 끌어 놓기 자체는 폴드8 창 나누기로 확인(사용자).

### 10. 키보드 단축키
- `MainActivity.dispatchKeyEvent`에서 화면이 쓰지 않은 키만 단축키로(글자 칸에 쓰는 동안은 그대로). 시스템 '단축키 보기'(메타+/)에 두 언어 목록.
- 포토샵과 같은 키: Ctrl+Z 실행 취소, Ctrl+Shift+Z·Ctrl+Y 다시 실행, V 이동, C 자르기, M 선택(사각형), L 올가미, W 자동 선택, B 브러시, E 지우개, T 텍스트, J 리터칭, O 명암, R 흐림, [ ] 크기, Shift+[ ] 경도, Ctrl+0 맞춤, Ctrl+1 100%, Ctrl+= / Ctrl+- 확대·축소, Ctrl+A·D·Shift+I 모두 선택·해제·반전, Ctrl+J 레이어 복제, Ctrl+E 아래와 병합, Ctrl+Shift+N 새 레이어, Delete 고른 곳 지우기, Enter 자르기 적용, Esc 자르기 취소·도구 닫기(편집 화면을 나가지는 않음), Space 누른 채 끌기 이동.
