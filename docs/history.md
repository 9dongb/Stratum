- 확인한 것

    - 이유: 첫 커밋부터 '실행 불가'(100644)로 기록돼 있어서, Mac에서 `./gradlew`가 "permission denied"로 멈췄다. 파일 내용은 그대로이고 Windows에는 영향이 없다.

    - Medium_Phone_API_37.0은 있었다. Pixel_Fold는 없어서 사용자가 Android Studio에서 만들었다(API 37.2, 16KB 페이지 이미지). 이름·화면 크기·접는 기기 설정이 원래 PC 기록과 같다.
    - 앱 안의 네이티브 라이브러리(`libandroidx.graphics.path.so`)는 16KB로 정렬돼 있어서, 16KB 페이지 이미지에서도 쓸 수 있다(zipalign 검사 통과).
  - 권한을 고친 뒤 `./gradlew assembleDebug test`가 바로 실행되고 통과했다(엔진 테스트 38개, 앱 1개).
