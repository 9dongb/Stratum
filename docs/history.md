# 작업 이력

끝난 작업을 **맨 위에** 하나씩 쌓는다. 지금 상태와 남은 일은 `docs/progress.md`에 있다.

항목마다 아래를 적는다.
- 날짜·제목
- 요청: 사용자가 요청한 것. 가능하면 사용자의 말 그대로 옮긴다.
- 의도: 사용자가 말한 목적. 말하지 않았으면 "말하지 않음"이라고 쓰고, 짐작해서 채우지 않는다.
- 커밋
- 바꾼 것
- 정한 것: 결정과 그 이유. 사용자가 추천안을 골랐으면 "추천 수용"이라고 표시한다.
- 확인한 것

새 항목은 그 작업의 커밋에 함께 넣으므로 자기 커밋 번호를 알 수 없다. 그래서 커밋 메시지를 적는다.
이 기록 방식을 만들기 전(2026-10-16 이전 세션)의 요청·의도는 원래 PC에만 있던 맥락에서 옮겨 적었다(2026-10-17). 거기에도 없으면 "기록 없음"이라고 쓴다.
